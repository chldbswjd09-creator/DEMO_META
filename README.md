# 광고 성과 분석 대시보드 — 포트폴리오 데모

Meta 광고 관리자 CSV를 업로드해 소재(광고) 단위 성과를 분석·판정하는 대시보드의 **포트폴리오 데모 버전**입니다.

> ⚠️ **샘플 데이터 데모입니다.** 실제 운영 데이터·회사 정보·매출 수치는 포함돼 있지 않으며, 실제 운영 서비스와 완전히 분리된 독립 프로젝트입니다.

## 특징 (데모 버전)

- **로그인 없음** — URL 접속 즉시 대시보드가 표시됩니다.
- **외부 DB 없음** — Supabase 등 데이터베이스에 연결하지 않습니다.
- **브라우저 로컬 저장** — 입력·수정 내용은 방문자의 브라우저(localStorage)에만 저장되며, 다른 방문자와 공유되지 않습니다.
- **샘플 데이터 자동 시드** — 처음 접속 시 가상의 샘플 분석 자료가 채워집니다. 우측 상단 **‘샘플 초기화’** 로 언제든 되돌릴 수 있습니다.
- **환경변수 불필요** — 별도 설정 없이 그대로 빌드·배포됩니다.

## 주요 기능

- 분석 자료(캠페인 CSV) 라이브러리 · 검색 · 정렬 · 캠페인 필터
- 소재별 성과 지표(CPM / CTR / CPC / CVR / ROAS / CPA) 자동 계산
- 운영 판단(유지 / 추가 관찰 / 스케일 / 중단 검토 등) 자동 판정
- 상세 분석 · 공유용 요약 · 소재별 수익성 비교
- BEP ROAS 계산기(손익분기 ROAS 산출)
- 여러 자료 통합 분석 · 기간(A/B) 비교
- CSV 업로드로 직접 분석 자료 추가 가능(데모 환경에서도 동작)

## 기술 스택

Next.js 14 (App Router) · TypeScript · Tailwind CSS · Recharts · PapaParse

## 로컬 실행

```bash
npm install
npm run dev
# http://localhost:3000
```

## 배포 (Netlify)

1. 이 저장소를 GitHub에 올립니다.
2. Netlify에서 해당 저장소를 연결합니다. 빌드 설정은 `netlify.toml`에 포함돼 있습니다.
   - Build command: `next build`
   - Plugin: `@netlify/plugin-nextjs`
3. **환경변수 설정 없이** 그대로 배포됩니다.

Vercel 등 다른 Next.js 호스팅에도 추가 설정 없이 배포할 수 있습니다.
